# app.velozready.com

Public pages for the VelozReady app, served by GitHub Pages at https://app.velozready.com.

- `index.html`: home page (coming soon). Hidden from search engines for now (`robots.txt` and `noindex`).
- `legal/`: the legal notices. **Generated, do not edit here.** They are built in the private app
  repository and copied over with `scripts/sync-public-site.mjs`.
- `confirmed.html`: where the sign-up confirmation email lands. Also copied from the app repository.
- `CNAME`: the custom domain.
